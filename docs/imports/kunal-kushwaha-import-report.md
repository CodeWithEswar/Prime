## 4. Problem & Progress Architecture

- **Independent Video Progress:** User video progress in Kunal's track is stored independently in `dsa_video_progress` and `dsa_playlist_enrollments`. Watching a video in Kunal's course does NOT automatically check off videos in Striver A2Z or other tracks.
- **Shared Canonical Problem Solving:** Shared coding problems between Striver A2Z and Kunal Kushwaha map to the canonical `public.problems` table via `leetcode_slug`. When a user solves a problem (e.g. *Build Array from Permutation*, *Two Sum*, *Valid Parentheses*, *N-Queens*), the solve status is recorded in `problem_attempts` and persists across BOTH courses simultaneously.
- **Assignment Progression:** The 18 official GitHub assignments have independent user tracking in `dsa_user_assignment_progress` with statuses: `NOT_STARTED`, `IN_PROGRESS`, `COMPLETED`, and `REVISIT`.
- **Chapter Progress:** Timestamp-level video chapters have independent tracking in `dsa_chapter_progress`.
